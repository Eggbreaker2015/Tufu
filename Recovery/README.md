# Unity 学习工程

唯一开发工程为 [StudyProject](StudyProject)，使用 Unity **6000.6.3f1**。双击本目录 `Open-StudyProject.cmd` 启动；首次克隆先在仓库根目录运行 `git lfs pull`。

完整打开步骤和工具说明见[仓库 README](../README.md)，源码入口见[学习导航](../Docs/Learning.md)，当前验证范围及限制见[恢复状态](../Docs/RecoveryStatus.md)。

保持正常 Domain Reload 和 Scene Reload，从 Boot 进入 Main。原始导出、逆向中间产物和历史诊断不随精简源码仓库提交。
