# Tufu Unity 学习工程

这是当前唯一继续开发的工程，使用 Unity **6000.6.3f1**。游戏逻辑、Shader 和依赖已进行重建，并已验证核心可玩链；它不是原作者源码，也未覆盖原作全部内容。

建议通过上一级 `Open-StudyProject.cmd` 启动。首次克隆先完成 Git LFS 下载，保持正常域和场景重载，按 Play 由 Boot 进入 Main。

具体步骤见[仓库 README](../../README.md)，代码入口见[学习导航](../../Docs/Learning.md)，验证结果和限制见[恢复状态](../../Docs/RecoveryStatus.md)。
