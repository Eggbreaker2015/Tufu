## 重复 Play 修复

此前关闭域和场景重载时，旧任务视图与 ECS 状态跨轮残留，初始化清理中断后引发系统组重复键错误。恢复正常 **Domain Reload + Scene Reload**，并补回 Morpeh 隐藏更新对象缺失的 Editor 退出销毁回调后，实际连续三轮 **Boot → Main → Stop** 均通过：每轮观察约 14 秒、6 项状态/真实存档检查、7 项 UI 检查，0 新增错误；隐藏 helper 在运行时为 1、停止后为 0。

这次修复没有改动 1,644 份游戏源和既有 175 份插件文件。提前释放 World 的失败方案已撤下。**关闭 Domain Reload 的快速 Play 仍不支持**，请保持域和场景重载开启。
