## 验证范围

- 地图宝箱全量配置核对通过；21 项独立规则及 7 项中断/池复用检查通过，实际验证属性、装备、灵魂奖励和重启防重。跨岛样例使用受控传送，测试后已恢复用户存档，不代表自然通关全部岛屿。宝箱原生地址与验证边界见[宝箱恢复](ChestRecovery.md)。
- 原摇杆的自然成长、武器/门解锁、第二岛进入和正常存档重启已实际跑通；部分高级功能使用隔离档或受控条件测试，不代表全部内容已自然通关。
- 刷新倒计时通过原摇杆接近并击倒树验证，显示原 `4m 0s` 并持续递减；视图回池和重复 Play 另有专项验证。
- 原商店按钮模拟支付、首充领取、VIP 每日奖励、广告永久属性和活动里程碑/结束补领已验证发放、保存及防重复；活动计划来自原 `SimulationData`。
- Shader 的 29 个改动通道选取代表性变体，顶点/片元共 70 项 D3D 编译检查通过。关闭阴影时，修复前后画面逐像素一致；开启时角色、钩链、树木及建筑投影可见。Game/Scene 各重绘 20 秒，153/305 个采样帧均稳定。
- 键盘改动通过 Editor 编译和 Main 启动；原摇杆释放、失焦、禁用/重启和实际 UI 文本框等 9 项运行检查通过。官方 CLI 不支持旧输入系统的按键注入，自动化没有验证物理键盘的持续按住/松开；使用时需先点击 Game 窗口获得焦点。
- 清理旧工具后，正常域/场景重载下连续两轮 Boot → Main → Stop 完成，最终编译、Shader 和 Console 错误均为 0；旧诊断类型及临时输入测试对象均为 0。

这些结果针对当前 Editor 和已验证场景。没有完整验证全部后期岛屿、活动全部阶段、高联盟、完整矿区、通行证全部领奖页面、Android、其它图形 API、VR 或移动端后台行为。ParticleImage 当前覆盖 CPU 分支，jobs 和部分噪声浮点差异仍有限制；部分旧活动及专用剧情镜头仍有空实现。

## 继续开发

保持 **Reload Domain 和 Reload Scene 均开启**；关闭域重载的快速 Play 尚不支持。修改脚本、插件和重建资源前先停止 Play，等待刷新及编译完成，再从 Boot 启动。

桌面阴影通过 [RecoveryDirectionalShadows.cginc](../Recovery/StudyProject/Assets/Shader/RecoveryDirectionalShadows.cginc) 适配恢复 Shader 的方向光分支，避免对屏幕遮罩重复应用强度和淡出；地面补用 Unity 内置 ShadowCaster 通道。原移动端阴影路径保留，但本次没有验证 Android。受影响材质关闭 GPU 实例化，运行时钩链副本继承该设置。

清理后只保留必要的启动保护、Addressables 重建依赖、编辑器生命周期兼容层及钻石工具。旧导出工程、一次性诊断脚本、文件轮询控制器、截图、日志和过程文档已移除；原 APK、原生分析资料和存档备份留在本地并由 Git ignore 排除。运行游戏不依赖这些研究资料。
