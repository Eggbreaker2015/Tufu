# 水晶峡谷（新地图，仅美术）

一张按第一关大小做的新地图，用来试一种和原作不同的地形。只有美术，没有刷怪、门、导航网格这些玩法内容。

- **场景**：`Recovery/StudyProject/Assets/Scenes/CrystalCanyon.unity`，单独的场景，没有改 `Main.unity`。
- **资源**：`Recovery/StudyProject/Assets/CrystalCanyon/`，其中 `Meshes/` 放 13 个网格，`Materials/` 放 6 个材质。
- **生成脚本**：`Tools/CrystalCanyon/`，运行 `python3 Tools/CrystalCanyon/build.py` 会重新生成上面的网格、材质和场景。
- **概念图**：[concept.png](concept.png)，用 Codex 生成，作为整体方向参考。

## 1. 大小和布局

能走的谷底约 76 × 114 米，和第一关（约 70 × 105 米）差不多。地面在 y = 0.05，x 向东，z 向北。

| 部分 | 位置 | 高度 |
|---|---|---|
| 入口 | 南边 (0, -50) 附近，相机对着这里 | 谷底 |
| 西侧高台 | (-28, 8)，从东边上台阶 | 4 米 |
| 东北高台 | (25, 33)，从南边上台阶；上面还有一层 8 米的小高台，也有台阶 | 4 米 / 8 米 |
| 中央小台 | (1, 15)，上面是最大的一簇水晶 | 3 米 |
| 东南高台 | (28, -36)，从西边上台阶 | 3 米 |
| 西南小台 | (-27, -37) | 2.5 米 |
| 水晶池 | (23, -7)，周围一圈石头和小水晶 | 水面 |

四周是三排玄武岩一样的多边形石柱，越往外越高，内排 8～13 米，外排 15～21 米。有些石柱顶上长水晶。谷底散着石头、石柱、水晶和干草。

`python3 Tools/CrystalCanyon/ascii.py` 可以打印一张俯视的文字高度图，用来检查布局。

## 2. 风格怎么和原作对上

- **几何**：和原作一样是大块面、平直着色的低多边形。每个三角形用自己的法线，所以是硬边。
- **上色**：
  - 石头、台阶、水晶和草都用原作的渐变色板 `TextureMain 2_1`，按高度取色，底部暗、顶部亮。
  - 材质都是原作材质的副本，只改了颜色：
    - `CC_Rock`：复制 `ArmyCampCliffs1`，紫色色调，阴影偏紫。
    - `CC_Crystal`：复制 `VolcanicCrystal`，略带自发光。
    - `CC_Props`：复制 `ArmyCampSide`，用于干草。
- **地面**：
  - 谷底 `CC_Floor` 和台顶 `CC_Top` 用原作的地面着色器 `Mobile/Diffuse Ground`，只是换了颜色。
  - 谷底用碎石纹理 `Ground_1`，淡紫色；台顶用沙纹 `sandHandpaint`，更浅的蓝紫色。
  - 谷底和第一关一样，铺 45 米见方的方块，带碰撞体。
- **光照**：太阳光、环境光和相机参数直接照搬 `Main.unity`。

## 3. 网格怎么生成

- **格式**：网格直接写成 Unity 原生的 `.asset` 文本格式，和项目里原有的 1436 个网格一样，没有经过 FBX 或 OBJ 导入。
- **结构**：地形网格分两个子网格，子网格 0 是石壁，子网格 1 是顶面。原作的悬浮岛块也是这么分的。
- **随机种子**：固定为 7。改 `layout.py` 里的位置或种子，重新运行 `build.py` 就能出一版新的。
- **GUID**：所有资源的 GUID 存在 `guids.json` 里，重新生成时保持不变，场景里的引用不会断。

## 4. 没做或要注意的

- 还没在 Unity 里看过实际效果。颜色、比例、水晶亮度都可能要调。
- 没有导航网格、刷怪、出生点、小地图，也没接进主世界。
- 只有谷底方块有碰撞体，石柱、高台和台阶都没有。
- 全图约 6.3 万顶点，其中水晶和干草占一半。物体都标成了静态，可以静态合批，但还没在手机上测过性能。
