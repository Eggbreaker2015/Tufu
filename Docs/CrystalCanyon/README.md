# 水晶峡谷（新地图，仅美术）

一张和第一关差不多大的新地图，用来试一种不同的地形。只有美术，没有刷怪、导航网格之类的玩法内容。

- **场景**：`Recovery/StudyProject/Assets/Scenes/CrystalCanyon.unity`，是一个单独的场景，没有改 `Main.unity`。
- **生成的资源**：在 `Recovery/StudyProject/Assets/CrystalCanyon/` 下，`Meshes/` 有 14 个网格，`Materials/` 有 6 个材质。
- **生成脚本**：在 `Tools/CrystalCanyon/` 下。运行 `python3 Tools/CrystalCanyon/build.py`，会重新生成上面的网格、材质和场景。
- **概念图**：[concept.png](concept.png)，用 Codex 生成，作为整体方向的参考。

## 1. 地图结构

能走的谷底约 76 × 114 米，和第一关的约 70 × 105 米差不多。地面在 y = 0.05，x 朝东，z 朝北。整张图按一条路线来组织，道具和装饰都跟着路和区域走，不是随机撒的。

装饰的摆放规则：

- **水晶**：大簇只放在地标上，包括中央台、祭坛、瞭望台、挖掘点和门塔。中等的水晶沿崖壁脚每隔一段放一簇，三种配色轮流用。小簇放在路的弯道外侧，和石头放在一起。
- **石头**：每处三块，从大到小排开。放在崖壁脚、高台脚和弯道外侧，路中间不放。
- **干草**：沿路两边交替种，石头堆旁边也有几丛。

## 2. 风格怎么和原作对上

- **几何**：
  - 和原作一样，是大块面、硬边的低多边形。
  - 四周是三排多边形石柱，越往外越高，内排 8～13 米，外排 15～21 米。
- **上色**：
  - 石头、台阶、水晶和干草都用原作的渐变色板 `TextureMain 2_1`，按高度取色，底部暗、顶部亮。
  - 用到的材质都是原作材质的副本，只改了颜色：
    - `CC_Rock` 复制自 `ArmyCampCliffs1`，紫色调，阴影也偏紫。
    - `CC_Crystal` 复制自 `VolcanicCrystal`，带一点自发光。
    - `CC_Props` 复制自 `ArmyCampSide`，原作道具和干草都用它，阴影改成紫色，和场景统一。
- **地面**：
  - 谷底用 `CC_Floor`，台顶用 `CC_Top`。两个都用原作的地面着色器 `Mobile/Diffuse Ground`，只换了颜色和纹理。
  - 谷底用淡紫色的碎石纹理 `Ground_1`，台顶用更浅的沙纹 `sandHandpaint`。
- **路**：
  - 网格是生成的带状网格。UV.x 横跨路宽，原作的路着色器用它把两侧边缘做淡出，和原作的 `Road Spline` 网格一样。
  - 材质直接用原作的 `Volcano_Road 1`。
- **原作道具**：
  - 用到的有：帐篷、木箱、木桶、矿车、路灯、栅栏、废墟、碎石、路牌、木门、火盆、码头、木板和地面碎石贴片。
  - 每种道具从 `Main.unity` 里取一个实例，记下它的网格、材质和世界旋转/缩放，存在 `props.json`。
  - 摆放时只在这个基础上再绕竖直轴转一下，并保留原作的埋入深度。
- **光照**：太阳光、环境光和相机参数照搬 `Main.unity`。

## 3. 网格怎么生成

- **Blender 建模**：崖壁石柱、高台、石头和水晶在 Blender 里建模，由 `blender_kit.py` 在后台跑，不开界面。`build.py` 会自动调用本机的 `/Applications/Blender.app`；加上 `--no-blender` 参数时，改用旧的纯 Python 几何。
  - **石柱**：玄武岩柱，中段有一道节理。前两排的竖棱倒了角，能接到一道高光。约三成柱子是斜断的顶；顶上放水晶的柱子和门塔保持平顶。
  - **高台**：先按台面轮廓做出分层的崖壁，每 1.6 米往里收一层，像岩层；再加噪声起伏，然后用 Decimate 减面，得到大小不一的块面。台面和边沿用顶点组保护起来，所以台顶仍然是平的。
  - **石头**：二十面体加噪声变形后大幅减面，每块约 76 个三角形，压扁后底部埋进地里。
  - **水晶**：六棱柱，各棱粗细不一，尖端的棱线高低错开，所以尖上的每个面都不一样。
- **其余部分**：台阶、路、干草和水面还是用 Python 直接生成。
- **格式**：Blender 只负责出几何体，网格最后还是写成 Unity 原生的 `.asset` 文本格式，和项目里原有的网格一样，所以不需要配 FBX 导入设置。
- **子网格**：地形网格分两个子网格，0 是石壁，1 是顶面。原作的悬浮岛块也是这样分的。
- **布局**：全部写在 `layout.py` 里，包括路的控制点、高台、营地、道具位置和装饰规则。随机种子固定为 7。
- **GUID**：存在 `guids.json` 里，重新生成时保持不变，场景里的引用不会断。
- **检查**：`python3 Tools/CrystalCanyon/ascii.py` 会打印一张俯视的文字地图，用来检查布局，其中路显示为 `.`。

## 4. 没做或要注意的

- 道具的朝向是按原作实例换算的，栅栏会顺着给定方向摆。还要在 Unity 里确认帐篷、矿车、门的朝向是否自然。
- 颜色、比例和水晶亮度都可能要再调。
- 没有导航网格、刷怪、出生点和小地图，也没有接进主世界。
- 只有谷底方块有碰撞体，石柱、高台和台阶都没有。
- 全图约 10 万顶点（按面拆开的平直着色），物体都标成了静态，还没在手机上测过性能。
